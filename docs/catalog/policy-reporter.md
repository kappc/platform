## Overview

The `policy-reporter` catalog chart deploys Policy Reporter, a monitoring and reporting tool for Kubernetes policy engines. It collects, visualizes, and exposes Prometheus metrics for policy validation results generated by Kyverno.

## Architecture

The chart vendors the upstream Policy Reporter Helm chart:

- **Core Reporter**: Watches the `PolicyReport` and `ClusterPolicyReport` resources created by Kyverno.
- **Web UI**: Shows policy results per namespace and policy.
- **Kyverno Plugin**: Adds Kyverno policy details to the UI.

## Dependencies

- **Upstream Chart**: `policy-reporter`, pinned in [Chart.yaml](../../kubernetes/catalog/policy-reporter/Chart.yaml).
- **Policy Engine**: The [Kyverno](kyverno.md) controller, which produces the reports.

## Configuration

Complete schema definitions, property types, and defaults are defined in [values.schema.json](../../kubernetes/catalog/policy-reporter/values.schema.json) and [values.yaml](../../kubernetes/catalog/policy-reporter/values.yaml).

Key configuration parameters:

- `policy-reporter.ui.enabled`: Enables the embedded web dashboard.
- `policy-reporter.plugin.kyverno.enabled`: Activates the Kyverno sub-plugin for rendering policy violations and cluster summaries.
- `policy-reporter.resources`: CPU and memory requests and limits for the core reporter and UI containers.

## Setup

Add an instance descriptor as described in [Instance Descriptors](../clusters/README.md#instance-descriptors). Recommended rollout group: `platform`. The UI is not exposed through the gateway; reach its `Service` with `kubectl port-forward`.
